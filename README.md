# Adithya Srirangam Financial Portfolio

Professional financial education and business ownership portfolio for Adithya Srirangam.

## Upload files to GitHub

Upload these files directly to the repository root:

```text
index.html
styles.css
script.js
README.md
logo.svg
favicon.svg
og-card.svg
```

## Add profile photo

Rename the profile photo to one of these names and upload it in the same place as index.html:

```text
adithya.jpeg
adithya.jpg
adithya.png
aadithya.jpeg
aadithya.jpg
aadithya.png
profile.jpeg
profile.jpg
profile.png
```

Recommended file name:

```text
adithya.jpeg
```
